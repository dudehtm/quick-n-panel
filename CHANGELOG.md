# Changelog

## 1.0.1 - 2026-09-01

- Added the public GitHub repository and issue tracker to the extension metadata.
- Removed the funding card and external Ko-fi link from the extension preferences.
- Removed custom keymap editing, capture, restoration, conflict detection, and
  diagnostics. Quick N-panel now only registers and unregisters its default `F5`
  shortcut; users can customize it in Blender's native Keymap preferences.
- Removed the `3D View` extension tag while retaining `User Interface`.
- Added public bug-report templates and automated unit tests.

## 1.0.0 - 2026-08-23

- Initial public release.
